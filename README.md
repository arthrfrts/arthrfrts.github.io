# arthr.dev

Personal portfolio site for [Arthur Freitas](https://arthr.dev). A single-page static site with no build step or dependencies.

## Structure

```
index.html   — markup
style.css    — styles
favicon.png  — favicon
cv.pdf       — curriculum vitae
```

## Fonts

[Atkinson Hyperlegible Next](https://fonts.google.com/specimen/Atkinson+Hyperlegible+Next) and [Atkinson Hyperlegible Mono](https://fonts.google.com/specimen/Atkinson+Hyperlegible+Mono), loaded via Google Fonts.
